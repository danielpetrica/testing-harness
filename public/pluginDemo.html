Readme.md

View on GitHub

This package allows you to manage user permissions and roles in a database. It is inspired by the standard Laravel Auth features but extends them for granular control.

Installation

You can install the package via composer:

composer require spatie/laravel-permission

You can publish the migration with:

php artisan vendor:publish --provider="Spatie\Permission\PermissionServiceProvider" --tag="migrations"

Usage

First, add the HasRoles trait to your User model(s):

use Spatie\Permission\Traits\HasRoles;

class User extends Authenticatable
{
    use HasRoles;
    // ...
}

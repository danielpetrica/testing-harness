How we calculate the Health Score

We use culturally neutral indicators to show reliability. We focus on maintenance, not just popularity.

01

Composer Analysis

We scan `composer.json` for **strict PHP versions** and latest Laravel constraints. If a package supports Laravel 12 but requires PHP 7.2, it loses points.

02

Pulse Check

Using GitHub API, we check for **commits in the last 6 months**. Abandonedware (no updates > 1yr) gets an immediate Low Health rating.

03

Health Indicators

Blue (3 Stars): Verified, Active, Safe.
Amber (2 Stars): Use with caution.
Gray (0-1 Star): Inactive/Risky.
